# Læringssti: Etikk og kunstig intelligens i forskerpraksis

Digital læringssti i Canvas (arbeidskrav i UH-ped). Nettbasert ph.d.-modul på én uke.

| Fil | Innhold |
|---|---|
| `laeringssti-mvp.pdf` | **MVP**: hele modulen side for side slik studenten ser den, med design-dokumentet som vedlegg |
| `design-dokument.md` / `.pdf` | Læringsutbytte, linjeinnretting, modulstruktur, sjekkliste mot arbeidskravet, manus (video, podkast), H5P, quiz, rubrikker, Mentimeter, byggeinstruksjoner, referanser |
| `refleksjonsnotat-utkast.md` / `.pdf` | Pedagogisk begrunnelse (konstruktiv linjeinnretting + Community of Inquiry) |
| `canvas-html/` | Ferdig HTML for hver Canvas-side/oppgave, med DesignPlus-struktur. Lim inn i HTML-editoren. |
| `bilder/banner.png` | Bannerbilde til startsiden (alt-tekst i design-dokumentet, del 13) |
| `bilder/ki-kompass-demo.png` | Skjermbilde av KI-bruk-kompasset |
| `../public/undervisning/ki-kompass.html` | KI-bruk-kompasset (vibe-kodet interaktiv modell), bygges inn i Canvas med iframe |
| `mvp/build.mjs` | Bygger PDF-ene på nytt: `cd mvp && npm install && node build.mjs` |

Plassholdere: `[[SETT INN: …]]` = innhold/lenke du må lage. `[[CHECK: …]]` = sjekk mot kilden.
